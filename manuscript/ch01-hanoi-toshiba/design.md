# 구조 설계도: 쥐꼬리 보상금과 '챌린지'

하노이 쥐 사냥 (1902) × 도시바 회계 부정 (2015) · 축 E(뜻밖의 결과) · 점수 93 (S) · [10. 품질 기준](../../docs/10-book-quality.md) 적용

## 한 장 설계도

| 항목 | 설계 |
|---|---|
| **핵심 질문** | 회사가 "숫자"를 요구할 때, 사람들이 만들어 내는 것은 성과일까 숫자일까 |
| **첫 장면** | 6월 12일 하노이의 장부: 20,114. "이 숫자는 정말 쥐를 센 것이었을까" → 인물이 없다는 약점 (아래 점검표 1번) |
| **걸린 것** | 하노이: 흑사병 방역이 무너진다 / 도시바: 이사 16명 중 8명 퇴진, 세 명의 사장, 회사의 신뢰 |
| **인물 (3명 이하)** | 하노이: 위생 검열관 (1차 자료 확보 후 실명·장면 추가) / 도시바: 다나카, 니시다, 사사키 (셋 다 등장하되 장면은 니시다 중심) |
| **열린 질문 순서** | Q1 숫자는 쥐였나? → Q2 왜 꼬리 없는 쥐가? → Q3 (전환) 113년 뒤 도쿄에도 꼬리가 있었나? → Q4 무엇이 "챌린지"였나? → Q5 왜 아무도 멈추지 못했나? → Q6 내 조직의 꼬리는? |
| **반전 위치** | ① 꼬리 없는 쥐 (전반부) ② 코브라 효과는 입증되지 않는 일화, 쥐는 입증된다 (신화 깨기) ③ 도시바에서는 꼬리를 자른 쪽이 아래가 아니라 **위에서 눌린 쪽**이라는 차이 (후반부) |
| **복선과 회수** | 전반: "장부에 적힌 것은 꼬리였다" → 후반: "결산서에 적힌 것은 이익으로 보이는 것이었다" |
| **겹침의 순간** | "두 장부" 단락. 그 전까지 "꼬리"와 "숫자"를 직접 연결하는 문장을 쓰지 않는다. 독자가 먼저 눈치채게 |
| **정보 배급** | 배경(흑사병, 파업)은 보상금 공고 장면 안에서 나눠 준다. 도시바 회계 4개 영역은 본문에서 생략하고 각주로만 |
| **이 비유가 맞지 않는 점** | ① 규칙 바깥에서 이용한 사람 vs 조직 안에서 눌린 사람 ② 합법 제도 vs 부적절 판정 ③ 규칙 설계자가 제도를 바꿈 vs 조사 대상이 됨 |
| **꼬리(끝) 문장** | "당신의 꼬리는 무엇입니까" → 이규호 코멘트 → 다음 꼭지 예고 |
| **창업자 코멘트 자리** | 마지막 20~30줄. 숫자 목표가 행동을 왜곡한 자신의 경험 (직접 작성) |

| 4 | 걸린 것이 숫자나 사람으로 구체적인가 | 예 | 하노이: 박람회와 페스트 / 도시바: 이사 8명, 1,518억 엔, 사업 매각 시사 |
| 5 | 이름 있는 인물이 세 명 이하인가 | 부분 | 반, 니시다, 다나카, 후카쿠시 4명. 다나카를 빼면 7/21 장면이 약해져 유지 |
| 6 | 반전이나 통념 뒤집기가 한 번 이상 있는가 | 예 | 서류철의 0, 꼬리 공장, 코브라 신화 |
| 7 | 앞의 복선이 뒤에서 회수되는가 | 예 | 서류철의 "보고된 숫자" → 도시바의 "557억 → 36억 엔" |
| 8 | 공통점이 설명이 아닌 발견으로 다가오는가 | 부분 | "두 장부"는 대구(對句)로 발견형이나 바로 뒤 (해석) 한 줄이 공통 구조를 적어 버림. 지우면 더 발견형 (선택) |
| 9 | 꼭지 끝 문장이 다음이 궁금하게 만드는가 | 보류 | 이규호 코멘트가 들어가야 판단 가능 |
| 10 | 결말을 제목과 첫 문단에서 이미 알려주지 않았는가 | 예 | |
