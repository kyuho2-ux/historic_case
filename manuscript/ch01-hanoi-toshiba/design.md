# 구조 설계도: 쥐꼬리 보상금과 '챌린지'

하노이 쥐 사냥 (1902) × 도시바 회계 부정 (2015) · 축 E(뜻밖의 결과) · 점수 93 (S) · [10. 품질 기준](../../docs/10-book-quality.md) 적용

## 한 장 설계도

| 항목 | 설계 |
|---|---|
| **핵심 질문** | 회사가 "숫자"를 요구할 때, 사람들이 만들어 내는 것은 성과일까 숫자일까 |
| **첫 장면** | 6월 12일 하노이의 장부: 20,114. "이 숫자는 정말 쥐를 센 것이었을까" → 인물이 없다는 약점 (아래 점검표 1번) |
| **걸린 것** | 하노이: 흑사병 방역이 무너진다 / 도시바: 이사 16명 중 8명 퇴진, 세 명의 사장, 회사의 신뢰 |
| **인물 (3명 이하)** | 하노이: 위생 검열관 (1차 자료 확보 후 실명·장면 추가) / 도시바: 다나카, 니시다, 사사키 (셋 다 등장하되 장면은 니시다 중심) |
| **열린 질문 순서** | Q1 숫자는 쥐였나? → Q2 왜 꼬리 없는 쥐가? → Q3 (전환) 113년 뒤 도쿄에도 꼬리가 있었나? → Q4 무엇이 "챌린지"였나? → Q5 왜 아무도 멈추지 못했나? → Q6 내 조직의 꼬리는? |
| **반전 위치** | ① 꼬리 없는 쥐 (전반부) ② 코브라 효과는 입증되지 않는 일화, 쥐는 입증된다 (신화 깨기) ③ 도시바에서는 꼬리를 자른 쪽이 아래가 아니라 **위에서 눌린 쪽**이라는 차이 (후반부) |
| **복선과 회수** | 전반: "장부에 적힌 것은 꼬리였다" → 후반: "결산서에 적힌 것은 이익으로 보이는 것이었다" |
| **겹침의 순간** | "두 장부" 단락. 그 전까지 "꼬리"와 "숫자"를 직접 연결하는 문장을 쓰지 않는다. 독자가 먼저 눈치채게 |
| **정보 배급** | 배경(흑사병, 파업)은 보상금 공고 장면 안에서 나눠 준다. 도시바 회계 4개 영역은 본문에서 생략하고 각주로만 |
| **이 비유가 맞지 않는 점** | ① 규칙 바깥에서 이용한 사람 vs 조직 안에서 눌린 사람 ② 합법 제도 vs 부적절 판정 ③ 규칙 설계자가 제도를 바꿈 vs 조사 대상이 됨 |
| **꼬리(끝) 문장** | "당신의 꼬리는 무엇입니까" → 이규호 코멘트 → 다음 꼭지 예고 |
| **창업자 코멘트 자리** | 마지막 20~30줄. 숫자 목표가 행동을 왜곡한 자신의 경험 (직접 작성) |

## 자체 점검표 (초고 v2 기준, 솔직한 평가)

| # | 문항 | 결과 | 메모 |
|---|---|---|---|
| 1 | 첫 200자에 인물과 위험한 순간이 있는가 | 예 (수수께끼형) | 역사학자 반(Vann)과 서류철. 위험보다 "왜 숫자가 0이 됐나"라는 수수께끼로 끈다 |
| 2 | 배경 설명이 300자 이상 이어지는 구간이 없는가 | 예 | 가장 긴 문단이 200자 안팎 |
| 3 | 섹션 끝마다 열린 질문이 남는가 | 부분 | "서류철", "2만 114마리", "꼬리"는 예. "꼬리 공장", "불붙은 쥐"는 결말·인용으로 끝나 약함 |
| 4 | 걸린 것이 숫자나 사람으로 구체적인가 | 예 | 하노이: 박람회·페스트·프랑스인의 위신 / 도시바: 이사 8명, 1,518억 엔, "매각이 된다" |
| 5 | 이름 있는 인물이 세 명 이하인가 | **아니오** | 반, 니시다, 시모미쓰, 후카쿠시, 다나카 5명. 장면마다 실명이 필요해 유지하되, 독자용 "인물 지도"나 별표 정리를 검토 |
| 6 | 반전이나 통념 뒤집기가 한 번 이상 있는가 | 예 | 0으로 끝난 서류철, 꼬리 공장, "이익이 아니라 앞당김", 사장의 "부끄러워서 공표할 수 없다" |
| 7 | 앞의 복선이 뒤에서 회수되는가 | 예 | 서류철의 "보고된 숫자"와 마지막 장의 0 → 도시바의 557억→36억, 마지막 숫자 −1,518억 엔 |
| 8 | 공통점이 설명이 아닌 발견으로 다가오는가 | 부분 | "두 장부"는 대구(對句)로 발견형이나 바로 뒤 (해석) 한 줄이 공통 구조를 적어 버림. 지우면 더 발견형 |
| 9 | 꼭지 끝 문장이 다음이 궁금하게 만드는가 | 보류 | 이규호 코멘트가 들어가야 판단 가능 |
| 10 | 결말을 제목과 첫 문단에서 이미 알려주지 않았는가 | 예 | |

**결과: 예 6 / 부분 2 / 아니오 1 / 보류 1.** 기준(8/10)은 이규호 코멘트와 3·5·8번 손질 뒤 재채점한다. 재미는 베타 독자 테스트 전에는 확정하지 못한다.

## 상태 (2026-09-30)

- **정합성·출처 게이트:** 발행 불가 사유 **1건** (이규호 코멘트 미작성). 원장의 참조 출처 38개 전부 `원문확인`. v0에서는 41건이었다.
- **분량:** 본문 약 5,400자. 코멘트(약 1,000~1,500자)를 넣으면 목표(6,000~8,000자) 하한을 넘는다.
- **출처의 한계:** Vann 2003 논문과 2018 단행본은 열람하지 못했다. 하노이 쪽은 Vann 본인의 발언(Made in China Journal 인터뷰, Freakonomics Radio 전사문), 학술 서평(H-France), 언론 기사(Saigoneer)로 구성했다. 보상금 액수(F2)·파업 시기(F4)는 원문 확정이 남아 있어 본문에서 "몇 센트" 등 흐리게 썼다.
