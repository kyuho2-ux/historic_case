# 01. 컨셉 & 포지셔닝

## 1. 무엇을 만드는가

전 세계와 한국사의 **실제 사건**을 골라, 그 사건 속 **한 번의 결정**을 중심으로 이야기를 풀고, 오늘 쓸 수 있는 **교훈 하나**로 마무리하는 스토리텔링 콘텐츠.

일반 역사 콘텐츠와 경영 케이스 스터디의 중간 지점에 선다.

```
            재미(스토리) ↑
                         |
   역사 예능/유튜브        |      ★ 역사 케이스 파일
   (재미 높음, 쓸모 낮음)   |      (재미 + 쓸모 + 출처)
 ────────────────────────┼──────────────────────→ 쓸모(교훈·적용)
   교과서식 역사 강의       |      경영 케이스 스터디(HBR 등)
   (재미·쓸모 모두 낮음)    |      (쓸모 높음, 재미 낮음)
```

## 2. 누구를 위한가

| 구분 | 타깃 | 이 사람이 원하는 것 | 우리가 주는 것 |
|---|---|---|---|
| 1차 (콘텐츠 소비자) | 25~45세 직장인, 팀장·리더, 창업자 | 출퇴근·점심시간에 "재미있으면서 남는" 교양 | 15분 안에 끝나는 이야기 + 대화 소재 + 일에 쓸 교훈 |
| 2차 (구매자) | 기업 HRD/교육 담당자, 컨퍼런스·도서관·지자체 기획자 | 지루하지 않고 참여율 높은 교육 콘텐츠 | 주제별 강연·워크숍 패키지 (리더십, 위기관리, 변화관리, 의사결정) |
| 3차 (확장) | 교사·학부모, 역사 애호가 | 수업·토론 자료 | 토론 질문이 포함된 케이스 카드 |

**핵심 인사이트:** 1차 타깃은 무료 콘텐츠로 모으고, 수익은 2차 타깃(B2B)에서 크게 난다. 1차 타깃의 상당수가 곧 2차 타깃의 의사결정자(팀장, HR 담당자)라는 점이 이 구조의 장점이다.

## 3. 차별점 (왜 이 채널인가)

1. **"결정의 순간" 중심 구성** — 연대기 나열이 아니라, 누군가 선택을 해야 했던 한 장면으로 시작한다. 시청자가 자연스럽게 "나라면?"을 생각하게 된다.
2. **신화 깨기(Myth Check)** — "코르테스가 배를 불태웠다", "튤립 파동으로 네덜란드 경제가 무너졌다"처럼 널리 퍼진 이야기의 실제를 확인한다. 반전의 재미와 신뢰를 동시에 얻는다.
3. **출처 공개 & 사실/해석 구분** — 매 편 참고문헌을 달고, 확인된 사실과 해석, 학계 논쟁을 구분해서 말한다. 강연 섭외 시 신뢰의 근거가 된다.
4. **세계사 × 한국사 교차** — 바사호 침몰과 조선 대동법처럼 시대·지역이 다른 사건을 같은 교훈 축으로 묶는다. 국내 역사 채널과도, 해외 콘텐츠 번역과도 다른 지점.
5. **교훈은 한 편에 하나만** — 교훈을 여러 개 늘어놓지 않는다. 기억에 남고, 강연 슬라이드 한 장으로 옮기기 쉽다.

## 4. 톤앤매너

- **말투:** 친한 선배가 술자리에서 들려주는 이야기처럼. 단, 과장과 단정은 피한다.
- **구조:** 첫 30초 안에 긴장된 장면 → 되감기로 배경 → 결정 → 결과 → 반전 → 교훈.
- **금지:** 특정 인물 영웅화/악마화, 출처 없는 숫자, 현재 정치 이슈에 억지로 빗대기, "역사가 증명한다" 같은 단정형 결론.
- **시그니처 멘트 예시:**
  - 오프닝: "오늘의 케이스 파일을 열어보겠습니다."
  - 전환: "자, 여기서 잠깐. 당신이 이 자리에 있었다면 어떻게 했을까요?"
  - 클로징: "사건은 끝났지만, 교훈은 오늘도 유효합니다."

## 5. 네이밍 후보

| 이름 | 느낌 | 장점 | 단점 |
|---|---|---|---|
| **역사 케이스 파일** (추천) | 탐정·사건 파일 | 호기심 + 신뢰, "케이스 스터디" 연상, 시리즈화 쉬움 ("파일 No.07") | 다소 딱딱할 수 있음 |
| 그날의 선택 | 드라마틱 | 감성적, 결정 중심 컨셉과 일치 | 교양/경영 느낌이 약함 |
| 히스토리 브리핑 | 비즈니스 | 직장인 타깃에 명확 | 재미 요소가 약함 |
| 역사는 답을 알고 있다 | 책 제목형 | 출판용으로 강함 | 채널명으로는 김 |

**제안:** 채널·브랜드명은 **「역사 케이스 파일」**, 책 제목은 별도로 **「역사는 가장 오래된 케이스 스터디다」** 또는 **「그날의 선택」** 처럼 대중적인 제목으로 가져간다. 사용 전 상표·채널명 중복 여부를 반드시 확인한다.

## 6. 비주얼 아이덴티티 방향

- 사건 파일 폴더, 기밀 도장("CASE No.012"), 옛 지도, 타자기 폰트를 모티프로.
- 썸네일 공식: **인물/장면 1개 + 짧은 질문형 카피 + 파일 번호**. 예) 바사호 그림 + "왕의 배, 1.3km도 못 가 가라앉다" + CASE 01.
- 매 편 마지막 화면은 동일한 **"교훈 카드"** 레이아웃 → 숏폼·SNS·강연 슬라이드에 그대로 재사용.
