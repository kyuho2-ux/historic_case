# 04. 수익화 모델

## 1. 기본 구조: 무료로 모으고, 강연으로 번다

```
 [무료]  유튜브 롱폼·숏폼 / 뉴스레터 / 블로그·브런치 / 케이스 카드 PDF
   │        → 목표: 신뢰와 이메일 리스트 확보
   ▼
 [저가]  전자책 케이스북 / 유료 멤버십(뉴스레터·유튜브) / 굿즈형 카드 세트
   │        → 목표: "돈 내는 팬" 확인, 소액 반복 수익
   ▼
 [중가]  온라인 강의(VOD) / 오프라인 북토크·세미나 / 종이책 출간
   │        → 목표: 전문가 포지션 확립
   ▼
 [고가]  기업 강연 / 리더십·조직 워크숍 / 교육 콘텐츠 라이선스 / 브랜디드 콘텐츠
            → 목표: 핵심 수익원
```

**핵심:** 같은 콘텐츠를 대중, 투자자, 경영자·관리자가 함께 본다(경영자·관리자도 이 분야 지식은 대중과 크게 다르지 않다). 그래서 콘텐츠는 하나로 만들고, **판매 채널만 나눈다.** 광고 수익(유튜브 애드센스)은 보너스로 생각한다. 역사·교양 채널이 광고만으로 생계를 유지하려면 매우 큰 조회수가 필요하다. 반면 강연은 구독자 수가 수천~1만 명 수준이어도 **책 1권 + 명확한 주제 + 좋은 강연 영상 샘플**이 있으면 시작할 수 있다.

## 2. 상품별 설계

> 아래 가격은 국내 시장에서 흔히 보이는 범위를 참고한 **출발점 가설**이다. 실제 가격은 경력·인지도·플랫폼 수수료·시장 조사에 따라 조정한다.

### 2-1. 디지털 상품

| 상품 | 내용 | 가격 가설 | 채널 |
|---|---|---|---|
| 케이스 카드 무료 PDF | 시즌 대표 케이스 3편 요약 + 토론 질문 | 무료 (이메일 수집) | 뉴스레터 가입 페이지 |
| 전자책 「역사 케이스 파일 Vol.1」 | 시즌1 12편 확장판 + 출처 + 토론 질문 | 1~2만 원대 | 자체 판매(스마트스토어 등), 전자책 플랫폼, 크몽 등 |
| 유료 멤버십 | 매주 심화 케이스, 비하인드 리서치 노트, 기업·산업 연표 자료, 월 1회 라이브 Q&A (종목 추천은 하지 않음) | 월 5천~1만 원대 | 유료 뉴스레터 플랫폼, 유튜브 멤버십 |
| 온라인 VOD 강의 | "역사로 배우는 의사결정/위기관리" 8~10강 | 수만~10만 원대 | 클래스형 강의 플랫폼 또는 자체 판매 |

### 2-2. 강연 상품 (핵심)

**상품명 예시:** 「이규호의 역사 케이스 파일: 기업의 갈림길은 역사 속에 먼저 있었다」

**강사 포지션:** 서울대 경영학과, 히토츠바시대 상학연구과에서 경영학을 공부하고, 20년간 여러 사업을 직접 창업·운영한 **"이론과 현장을 모두 아는 창업자"**. 전문 강사나 교수와 달리 결정의 무게를 직접 겪어 본 사람이라는 점을 앞세운다.

| 패키지 | 구성 | 대상 |
|---|---|---|
| **키노트 강연 (60~90분)** | 케이스 3~4개 스토리텔링 + 핵심 교훈 3개 | 기업 월례 조회, 컨퍼런스, 도서관·지자체 교양 강좌 |
| **리더십 워크숍 (3시간)** | 케이스 2개 + "나라면?" 조별 토론 + 우리 조직 적용 실습 | 팀장·신임 리더 교육 |
| **교육 과정 라이선스** | 케이스 카드 + 퍼실리테이터 가이드 + 슬라이드 | 기업 HRD 부서, 교육 회사 |

**주제 메뉴 (5개 테마 축과 연결):**

| 강연 주제 | 사용 케이스 예 |
|---|---|
| 불확실성 속의 의사결정 | 노르망디 × 인텔 메모리 철수, 세종과 최만리 × 삼성 도쿄 선언 |
| 사이클과 투자의 타이밍 | 튤립 신화 × SK하이닉스, 이사벨라 × 손정의 |
| 위기의 리더십과 재건 | 섀클턴 × JAL 이나모리 가즈오 |
| 지키려다 잃는다 (혁신의 딜레마) | 적기조례 × 블록버스터, 마지노선 × 샤프 |
| 말할 수 없는 조직은 가라앉는다 (조직문화) | 바사호 × 갤럭시노트7 |
| KPI의 함정: 측정하는 대로 움직인다 | 하노이 쥐 사냥 × 도시바 |
| 플랫폼과 표준 선점 | 로마 가도 × 엔비디아, 백과전서 × 네이버 지식iN |
| 불가능한 프로젝트를 끝내는 조직 | 수원화성 × 현대 조선소 |
| 일본 기업에서 배우는 한국 기업의 내일 (특화 강연) | 도시바, 샤프, JAL, 소프트뱅크 (일본 1차 자료 기반) |

**강연 섭외를 위한 준비물:**
1. 강연 소개서 1장 (주제 메뉴, 대상, 시간, 형식, 이규호 이력: 서울대 경영·히토츠바시 상학연구과·20년 창업 운영)
   - 20년간 운영한 사업체와 대표 성과·실패 경험을 구체적으로 채운다. 강연 섭외는 이 한 줄에서 결정되는 경우가 많다
2. 강연 샘플 영상 3~5분 (**아바타가 아닌 본인 출연**으로 촬영. 섭외 담당자는 실제 강연 능력을 확인하고 싶어 한다)
3. 책 또는 전자책 (신뢰 근거)
4. 참가자 후기
5. 강연 에이전시·강사 섭외 플랫폼 등록, HRD 담당자 대상 뉴스레터 발송
6. 기존 사업 네트워크 활용: 20년간 만난 경영자·거래처가 첫 강연의 가장 현실적인 고객이다

### 2-3. 출판

- **경로 A (추천):** 블로그/브런치 연재 → 반응 데이터 축적 → 출판사에 기획서 + 연재 링크로 투고. 이미 독자가 있다는 증거가 출간 확률을 높인다.
- **경로 B:** 전자책 자가 출판으로 먼저 판매 → 판매 실적을 근거로 종이책 제안.
- 책은 수익 자체보다 **강연 단가와 섭외율을 올리는 명함**으로 가치가 크다.

### 2-4. 기타 수익원

- **브랜디드 콘텐츠/협찬:** 교육·금융·HR 서비스 등 "교훈" 톤과 맞는 브랜드와 협업. 콘텐츠 신뢰를 해치지 않도록 광고 표기와 선별 기준을 둔다.
- **교육 기관 라이선스:** 학교·학원용 토론 수업 자료 (케이스 카드 + 교사용 가이드).

## 3. 수익 구조 단계별 기대치 (가설)

| 단계 | 시점 (예상) | 주 수익원 | 비고 |
|---|---|---|---|
| 1단계 | 0~3개월 | 거의 없음 | AI 자동화로 발행량을 빠르게 늘려 구독자·이메일 리스트를 쌓는 시기 |
| 2단계 | 3~6개월 | 전자책, 멤버십, 네트워크 기반 첫 강연 | 첫 유료 전환 검증 |
| 3단계 | 6개월~ | 기업 강연·워크숍, 출판, VOD | 강연 비중이 가장 커지는 구조가 목표 |

## 4. 수익화 원칙

1. **무료 콘텐츠의 품질을 유료 수준으로** — 무료가 곧 가장 강력한 영업 자료다.
2. **이메일 리스트를 직접 소유한다** — 플랫폼 알고리즘이 바뀌어도 독자와 직접 연결된 채널이 필요하다.
3. **팔기 전에 물어본다** — 전자책·강의 제작 전에 뉴스레터 독자에게 설문·사전예약으로 수요를 확인한다.
4. **신뢰를 파는 비즈니스** — 과장된 광고, 출처 없는 자극적 썸네일은 단기 조회수를 올려도 강연 수익을 깎는다.
