# 05. 12개월 로드맵 & KPI

> 아래 목표 수치는 방향을 잡기 위한 **가설**이다. 1단계 결과를 보고 다시 설정한다.

## 0단계: 준비 (0~1개월)

- [ ] 채널·브랜드명 확정 및 중복·상표 확인 (「역사 케이스 파일」 우선 검토)
- [ ] 뉴스레터, 유튜브, 숏폼 계정 개설 / 로고·썸네일·교훈 카드 템플릿 제작
- [ ] 시즌1 12편 중 **최소 4편 원고를 미리 비축** (연재 공백 방지)
- [ ] 출처 관리 방식 결정 (스프레드시트 또는 노트 앱에 에피소드별 출처 등급 기록)
- [ ] 무료 리드 자료 "케이스 카드 3종" PDF 제작

## 1단계: 파일럿 & 검증 (1~3개월)

**목표:** 어떤 소재·포맷이 반응하는지 데이터로 확인

- 주 1회 뉴스레터/블로그 발행 (총 12편)
- 주 2~3개 숏폼 발행
- 반응 좋은 상위 3~4편만 롱폼 영상으로 제작
- 매 편 "다음에 듣고 싶은 역사 케이스는?" 질문으로 소재 수집

| KPI | 검증 질문 |
|---|---|
| 뉴스레터 구독자 수, 오픈율 | 글 형태로도 사람들이 이 컨셉을 좋아하나? |
| 숏폼 평균 조회수, 프로필 유입 | 어떤 훅이 먹히나? (신화 깨기 vs 위기 드라마 vs 한국사) |
| 롱폼 평균 시청 지속률 | 15분 포맷이 적당한가? |
| 답장·댓글의 내용 | 사람들이 '재미'에 반응하나, '교훈'에 반응하나? |

**3개월 차 판단:** 가장 반응 좋은 테마 축 1~2개에 집중하고, 반응 없는 포맷은 줄인다.

## 2단계: 성장 & 첫 수익 (4~6개월)

- 롱폼 영상 격주 → 주 1회로 확대 (편집 외주 검토)
- 시즌1 완결 → 전자책 「역사 케이스 파일 Vol.1」 사전예약 → 출간
- 첫 오프라인 이벤트: 소규모 북토크/세미나 (유료 또는 무료) → **강연 샘플 영상 촬영**
- 강연 소개서 1장 제작

| KPI | 기준 (가설) |
|---|---|
| 이메일 구독자 | 1,000명 이상 |
| 전자책 판매 | 첫 달 100부 이상 |
| 오프라인 이벤트 | 1회 이상, 참가자 후기 확보 |

## 3단계: 강연 진입 (7~9개월)

- 강연 에이전시·섭외 플랫폼 등록, 지인 네트워크·HRD 담당자 대상 제안
- 도서관·지자체·대학 교양 강좌부터 시작해 레퍼런스 축적
- 유료 멤버십 오픈 (심화 케이스 + 리서치 노트)
- 출판사 투고 (연재 반응 데이터 + 전자책 판매 실적 첨부)

| KPI | 기준 (가설) |
|---|---|
| 강연 | 월 1~2회 |
| 유료 멤버 | 100명 이상 |
| 출판 | 출판사 미팅 1건 이상 |

## 4단계: 확장 (10~12개월)

- 기업 워크숍 패키지 정식 출시 (3시간 과정 + 퍼실리테이터 가이드)
- 온라인 VOD 강의 제작 (가장 반응 좋은 강연 주제 1개)
- 시즌2 기획: 1년간 쌓인 소재 요청과 데이터를 바탕으로
- 종이책 계약 또는 원고 집필

| KPI | 기준 (가설) |
|---|---|
| 기업 강연·워크숍 | 월 2~4회 |
| 재섭외율 | 20% 이상 |
| 수익 구성 | 강연·교육 비중 50% 이상 |

## 매달 확인할 체크포인트

1. 이번 달 가장 반응 좋았던 편과 그 이유는?
2. 팩트 오류 지적이 있었나? 정정은 했나?
3. 콘텐츠 → 이메일 → 유료 전환 흐름 어디서 가장 많이 빠지나?
4. 강연 문의로 연결된 콘텐츠는 무엇이었나?
5. 제작 속도는 지속 가능한가? (번아웃 방지: 원고 비축량 4편 이상 유지)
