# 08. AI 자동화 제작 파이프라인

## 1. 원칙

제작 분량은 AI 도구로 자동화한다. 리서치 보조, 원고 초안, 번역, 이미지, 자막, 편집, 그리고 **이규호의 보이스 클론과 아바타 내레이션**까지 자동화한다.

대신 자동화가 커질수록 두 가지 리스크도 커진다. 그래서 **사람이 반드시 확인하는 관문 3개**를 둔다.

| 리스크 | 왜 커지나 | 대응 |
|---|---|---|
| **사실 오류** | AI는 그럴듯한 인용문, 숫자, 날짜를 만들어낸다. 이 채널의 핵심 자산인 신뢰를 한 번에 무너뜨릴 수 있다 | 관문 1: 출처 대조 |
| **"찍어낸 콘텐츠"로 분류될 위험** | 유튜브는 대량 생산·반복형 콘텐츠를 수익화에서 제외하는 정책(inauthentic content)을 운영한다. 템플릿만 바꾼 듯한 영상은 수익 창출이 막힐 수 있다 | 관문 2: 이규호의 관점 삽입 |
| **AI 생성 표시 의무** | 플랫폼은 사실적인 합성·변형 콘텐츠에 표시를 요구하고, 한국도 AI 기본법(2026년 시행)으로 생성형 AI 표시 규정을 두고 있다 | 관문 3: 공개와 표시 |

## 2. 파이프라인

```
① 소재 선정      data/candidates.csv 점수 → S·A등급 선택                      [사람]
      │
② 리서치 수집    AI 리서치 도구로 1차 자료·논문·보고서·기사 수집, 출처 목록 자동 생성   [AI]
      │          일본 자료: 일본어 원문 수집 → 번역 초안                          [AI]
      │
③ ★관문 1       핵심 주장(숫자·날짜·인용문·인과관계)을 원문과 대조                   [사람]
   출처 대조      출처 등급(S/A/B/C) 확정, 불확실한 것은 "그렇게 알려져 있다"로 표기
      │
④ 원고 초안      CASE 구조 + 겹쳐 보기 구조로 원고 초안 (글 버전 → 영상 대본 버전)    [AI]
      │
⑤ ★관문 2       창업자 코멘트 작성, "나라면?" 질문, 교훈 한 줄 확정                  [사람]
   이규호의 관점   원고 전체를 이규호의 말투와 의견으로 다듬기
      │
⑥ 제작          보이스 클론 내레이션, 아바타 영상, 이미지·지도·차트 생성, 편집, 자막     [AI]
      │          숏폼 3~5개 자동 컷, 썸네일 후보 생성, 케이스 카드·강연 슬라이드 생성
      │
⑦ ★관문 3       최종 시청 검수 (사실·어조·저작권), AI 사용 표시, 면책 문구 확인       [사람]
   검수와 표시
      │
⑧ 발행·측정      뉴스레터·유튜브·숏폼 발행, 반응 데이터를 candidates.csv 보정에 반영   [AI+사람]
```

### 사람이 들이는 시간 (편당 목표)

| 관문 | 목표 시간 | 할 일 |
|---|---|---|
| 관문 1 출처 대조 | 1~2시간 | 핵심 주장 10개 안팎을 원문과 대조 |
| 관문 2 관점 삽입 | 1시간 | 창업자 코멘트, 의견, 말투 |
| 관문 3 최종 검수 | 30분~1시간 | 완성본 시청, 표시·면책 확인 |

> 자동화로 절약한 시간은 **관문 1과 2에 다시 투자**한다. 이 두 관문이 다른 AI 자동화 채널과 이 채널을 가르는 지점이다.

## 3. 아바타·보이스 클론 운영 원칙

- **공개한다:** 채널 소개와 영상 설명란에 "내레이션과 영상 일부는 이규호 본인의 AI 음성·아바타로 제작합니다"라고 밝힌다. 유튜브 업로드 시 합성 콘텐츠 표시 항목도 해당하면 체크한다. 숨겼다가 드러나면 신뢰 비용이 훨씬 크다.
- **실제 얼굴과 섞는다:** 채널 오프닝, 분기별 라이브, 강연 영상은 본인이 직접 출연한다. 강연 섭외 담당자는 "실제로 말을 잘하는 사람인가"를 확인하고 싶어 하기 때문이다.
- **클론 데이터 관리:** 음성·얼굴 학습 데이터와 도구 계정은 본인만 접근하도록 관리하고, 도구의 이용 약관(상업적 이용, 데이터 보관)을 확인한다.

## 4. 저작권·자료 사용

- **역사 이미지:** 퍼블릭 도메인(오래된 판화·지도·회화)을 우선 사용한다.
- **기업 이미지:** 로고·제품 사진·보도 사진은 저작권과 상표 문제가 있다. AI로 만든 일러스트와 직접 만든 차트로 대체하고, 실제 사진이 필요하면 라이선스를 확인한다.
- **AI 생성 이미지:** 실존 인물을 사실적으로 합성하지 않는다. 역사 인물도 "재현 이미지"임을 표시한다.

## 5. 도구 선택 기준

도구는 빠르게 바뀌므로 특정 제품에 묶이지 않도록 기준만 정한다.

1. 한국어·일본어 품질 (특히 보이스 클론의 한국어 억양)
2. 출처 링크를 함께 주는 리서치 도구인가
3. 상업적 이용 허용 여부와 학습 데이터 정책
4. 원고 → 영상 → 숏폼까지 자동으로 이어지는 연동성
5. 월 비용 대비 편당 제작 비용
