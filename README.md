# 역사 케이스 파일 (History Case Files)

> **"역사는 가장 오래된 케이스 스터디다."**
> 실제로 있었던 사건을 한 편의 이야기로 풀고, 그 안에서 오늘의 일과 삶에 쓸 수 있는 교훈 하나를 꺼내는 콘텐츠 프로젝트.

## 한 줄 컨셉

**"스토리는 역사책처럼 재미있게, 교훈은 경영서처럼 쓸모 있게, 출처는 논문처럼 정직하게."**

- **스토리성** — 모든 에피소드는 "결정의 순간"을 중심으로 한 기승전결 구조
- **신뢰성** — 에피소드마다 출처와 '사실 / 해석 / 논쟁' 구분 표기
- **호기심** — "그때 당신이라면?" 질문과, 널리 알려진 이야기의 반전(신화 깨기)
- **쓸모** — 매 편 끝에 현업에 옮길 수 있는 교훈 하나 → **기업 강연·교육으로 연결되는 핵심 고리**

## 핵심 전략 요약

1. **원 소스 멀티 유즈**: 리서치 1회 → 글(뉴스레터/블로그) → 롱폼 영상 → 숏폼 3~5개 → 강연 모듈. 한 편의 조사 비용으로 다섯 가지 결과물을 만든다.
2. **글로 먼저 검증, 영상은 그다음**: 제작 비용이 낮은 뉴스레터와 숏폼으로 어떤 소재가 반응하는지 확인한 뒤, 반응이 좋은 소재만 롱폼 영상과 책으로 키운다.
3. **수익화의 중심은 B2B 강연**: 조회수 광고 수익보다 "역사 케이스로 배우는 리더십/위기관리/변화관리" 같은 기업 교육 상품이 단가와 지속성이 높다. 모든 콘텐츠를 처음부터 '강연 모듈'이 되도록 설계한다.
4. **책은 결과물이자 명함**: 시즌 1~2의 콘텐츠를 묶어 전자책 → 종이책 출간 제안으로 이어가고, 책은 강연 섭외의 신뢰 근거가 된다.
