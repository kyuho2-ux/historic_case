# 이규호의 역사 케이스 파일 (History Case Files)

> **"기업의 갈림길은 언제나 역사 속에 먼저 있었다."**
> 역사 속 사건 하나와 한국인이 아는 기업의 갈림길 하나를 **겹쳐 보는** 스토리텔링 콘텐츠.
> 화자는 서울대 경영학과·히토츠바시대 상학연구과에서 공부하고 20년간 여러 사업을 창업·운영해 온 **이규호**.

예:
- **하노이 쥐 사냥 (1902) × 도시바 회계 부정 (2015):** 측정하는 대로 움직이고, 압박하는 대로 숫자를 만든다
- **바사호 (1628) × 갤럭시노트7 (2016):** 아무도 "안 됩니다"라고 말하지 못한 배와, 멈출 줄 안 회사
- **튤립 파동 신화 (1637) × SK하이닉스 (2002~2024):** 모두가 거품이라 부를 때 바닥에서 내린 결정

## 컨셉

**"스토리는 역사책처럼 재미있게, 교훈은 경영서처럼 쓸모 있게, 출처는 논문처럼 정직하게."**

- **겹쳐 보기** — 익숙한 기업 이름이 문을 열고, 낯선 역사 사건이 새로운 각도를 준다
- **이규호의 관점** — 경영학 연구 + 20년 창업 현장 + 일본 1차 자료. 매 편 끝에 "창업자의 코멘트"
- **하나의 눈높이** — 경영자도 관리자도 투자자도 대중과 관심사가 같다. 콘텐츠는 하나, 판매 채널만 나눈다
- **신뢰** — 출처 공개, 사실·해석·논쟁 구분, 신화 깨기, 공개 정정
- **AI 자동화 + 사람의 관문** — 제작은 자동화하고, 출처 대조·관점·검수는 사람이 지킨다

## 핵심 전략 요약

1. **겹쳐 보기가 차별점:** 기업 단독 이야기는 이미 많다. 역사 사건과 짝지어 새로운 각도를 만든다.
2. **화자가 해자:** 일본 기업 사례의 1차 자료와 20년 창업 경험의 코멘트는 다른 채널이 따라 하기 어렵다.
3. **소재는 점수와 등급으로:** 인지도·결정·낙차·반전·신선도·겹쳐 보기·현재성·검증·화자 적합도의 100점 모델.
4. **자동화로 양을, 사람으로 질을:** 제작은 AI와 아바타로 자동화하고, 사람의 시간은 출처 대조와 관점에 쓴다.
5. **6주 검증 후 확대:** 겹쳐 보기 vs 기업 단독, 한국 vs 일본 기업을 A/B로 비교한 뒤 형식을 확정한다.
6. **수익의 중심은 강연:** 콘텐츠 → 전자책·멤버십 → 사업 네트워크 기반 첫 강연 → 기업 강연·워크숍.
